# References

This folder stores background papers and related benchmark work that motivated FaithRightsBench.

## Papers

- `papers/religiousbiaslandscape.pdf`
  - Religious bias landscape paper covering text LLMs and text-to-image models, including mask filling, prompt completion, image generation, and prompt-based debiasing.

- `papers/cognitivebias.pdf`
  - Study of how generative AI can influence religious cognition and religious education through biased generated content.

- `papers/Faith__Framing__and_Safety_in_Relationship_Advice.pdf`
  - Faith-conditioned relationship-advice benchmark that varies user religion and measures differences in advice framing and safety response.

## Related External Work

- CEFE-AI / AllFaith Benchmark: https://cefeai.org/
- CEFE-AI GitHub: https://github.com/CEFEAI

FaithRightsBench is inspired by these works, but focuses on a different question: whether LLMs provide equal practical, rights-based, and supportive guidance across religious identities in accommodation and discrimination scenarios.
